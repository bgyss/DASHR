The maximum channel difference is 153; large differences are sparse and concentrated around thin contour details and localized shading boundaries. They are not hidden by the background-dominated whole-frame average. Smaller differences may arise from backend arithmetic, filtering or material decoding, but this comparison does not establish their cause.

Foreground is estimated from RGB differing from each image's corner background. The Windows capture has no independent primary/shadow status, UV, normal or depth planes, so coverage is a proxy, not the roadmap's full hit/depth acceptance test. This one roof-textured tube pose provides strong single-frame translation evidence. It does not establish parity across materials, distortion modes, animation or pathological seams, and does not resolve Windows Rust DX12 device loss.

Reproduce the Mac capture from the repository root:

```sh
scripts/in-nix cargo run --locked --release --features viewer -- capture \
  --settings fixtures/windows-tube-snapshot.json --out out/windows-tube-replay
```
